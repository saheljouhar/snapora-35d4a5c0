# Snapora
QR-based wedding photo sharing app built from scratch.

## What it does
Guests scan a QR code at a wedding and upload photos instantly.
The couple gets all photos collected in one place — no app download needed.

## Problem it solves
Wedding photographers miss candid moments. Guests have hundreds of 
photos on their phones that never get shared. Snapora fixes that.

## Tech stack
- React + Vite (frontend)
- Supabase (database and storage)
- QR code generation
